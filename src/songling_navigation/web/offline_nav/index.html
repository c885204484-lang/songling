接实车：现有底盘、激光雷达、GPS 定位

在小车 / Jetson 终端执行，先停止原网页服务和原导航 launch，以免端口或节点重复。 

cd ~/songling/songling_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch songling_navigation gps_navigation.launch.py use_offline_map:=True

此命令恢复已保存地图，默认仅规划。实车启动参数 offline_enable_motion:=True 可启用行驶。卫星底图必须先与 RTK / SLAM 的 map 坐标配准，当前未配准底图会被拒绝用于实车导航。

先用模拟小车连接

ros2 launch songling_navigation offline_navigation.launch.py demo:=true enable_motion:=true

两种启动方式选一种。仿真默认起点为 map (0, 0)，需落在可行驶区。启动后刷新本页，保存并应用地图，再选终点、仅规划。

跨设备时 ROS_DOMAIN_ID 需一致，并允许 DDS 通信。浏览器仍访问运行服务的地址；同机为 http://127.0.0.1:8080。

导入离线地图

选择 ROS 地图 YAML 和它对应的 PGM / PNG 图片。恢复园区地图包时，同时选择 basemap.png 彩色底图，可一并载入 project.json。
