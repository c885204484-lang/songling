# 动态安全距离方案：现有专利对照与差异化设计说明

检索日期：2026年11月5日。配套文稿：《无人车窄通道动态安全距离控制方法及系统》。本说明供技术方案评审和代理人进一步检索使用，不属于专利说明书正文。

## 本次形成的方案

本稿针对“默认中心到边界距离0.65 m导致0.90 m窄路被关闭”的具体问题，构造“不可压缩下限＋默认附加距离×保留系数”的双侧距离模型。先按两侧共同净空预算筛选，再以保留完整车辆状态的前向可达、后向可续行和停车分支共同决定是否释放附加距离。

拟主张的是上述计算与控制之间的组合关系。车辆轮廓支持函数、运动原语、可达性分析、制动扫掠和误差预算分别具有已有技术基础，不能仅因将这些名称写入稿件就认定产生创造性。

## 独立权利要求的设计重心

| 本稿权利要求1的环节 | 必须保留的技术关系 | 可用于验证的具体结果 |
|---|---|---|
| S1 原始边界 | 在默认0.65 m派生掩码之外保存可重新计算的原始区域。 | 固定掩码已封闭时仍能取得原始0.90 m几何通道。 |
| S2 双侧分解 | 左右下限分别由车身及有效误差确定，只有默认值超过下限的部分可调。 | 下限超过通道容量时拒绝，不把误差强行裁小。 |
| S3 净空分配 | 同一保留系数与两侧可分配距离共同形成状态约束。 | 0.90 m算例可产生0.43 m双侧阈值；不对称误差产生不同阈值。 |
| S4 状态连接 | 位置、航向、速度和转向状态共同参与连接，检查完整扫掠。 | 端点安全但转弯外摆越界的连接被删除。 |
| S5 双向筛选 | 前向可达与出口后向可续行在同一状态图上相交，并保留停车分支。 | 各截面有空间、但相邻运动不可执行时拒绝进入。 |
| S6 控制输出 | 许可来源于同一贯通状态链，首段指令及停车分支与之关联。 | 当前速度不满足低速模型时，先验证入口降速过程。 |

## 算例与技术审查记录

文稿中的0.90 m对称算例：两侧下限各0.40 m，可分配距离各0.25 m，参考点区间预留宽度0.04 m，得到λ上界0.12，两侧动态中心阈值各0.43 m，参考点区间为[0.43,0.47] m。

不对称算例：左下限0.42 m、右下限0.38 m，λ=0.12时，左阈值0.4476 m、右阈值0.4124 m，参考点区间为[0.4124,0.4524] m。坐标原点在右边界，区间中心为0.4324 m。

这些是用于检查公式和几何含义的参数推演。0.08 m误差及基础净距合计为假设条件，尚未标定；未提供实车通过率或性能提升比例。正文第十二节给出了四组对照试验，后续证据应重点支持“双侧分配＋连续状态链”相对简单缩距方案的效果。

1. 进一步检索动态中心距离、左右净空分配、最大最小附加余量、具有停车分支的通道可达性，以及这些要素的组合；同时查阅相关论文。
2. 对表中中国文件的有效独立权利要求逐项制作产品实施对应表，核对其官方当前文本及同族。尤其关注产品是否又加入“两等候点调整统一膨胀”或“子边界对中心构建凸走廊”等流程。
3. 对实际软件的数据流进行核对：保留真实轮廓和原始禁行区；规划与控制共享有状态约束；已经包含车身尺寸的参考点可行域不得再次按同一车身尺寸重复收缩。
4. 完成误差模型标定、入口和出口过渡验证、局部可行但无法连续通过的反例及停车分支对照试验，再据结果调整权利要求。
